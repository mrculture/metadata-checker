# Metadata Checker

Static micro-site for auditing page metadata before launch.

## Features

- Paste raw HTML or fetch a CORS-friendly URL
- Check title, description, canonical, robots, viewport, language, Open Graph, and Twitter Card tags
- Preview search and social card output
- Generate a recommended metadata snippet
- Copy tags or download a Markdown report

## Production URL

https://metadata-checker.utilityshelf.site/

## Open

Open `index.html` in a browser. No build step is required.

Browsers may block direct URL fetching for sites that do not allow cross-origin reads. In that case, paste the page HTML into the Raw HTML field.
